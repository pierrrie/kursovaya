# MKB-S3 DLL

Проект использует `ctypes` и пытается загрузить `mkb_s3.dll` из этой папки.

Сейчас в репозитории лежит исходник-заготовка `mkb_s3_stub.c`.  
Чтобы собрать DLL в Windows (MinGW):

```bash
gcc -shared -o mkb_s3.dll mkb_s3_stub.c
```

После сборки файл `mkb_s3.dll` будет автоматически подхвачен приложением при старте.
